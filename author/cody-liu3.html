解決開啟 android emulator 記憶體用量不足的問題

2016 February 18 Thu

最近 Android 2.0 新推出 Emulator 比過去的效能好很多，所以就從用 Genymotion 改回用 Google 的 Emulator，但是在開發的時侯，發生一個小問題，在我的 Mac 上面沒辦法同時間開多個 Emulator，會出現以下錯誤訊息:

emulator: The memory needed by this VM exceeds the driver limit. HAX is not working and emulator runs in emulation mode

在 OSX 的解決方案如下:

找到 Android SDK 裡面的 android-sdk-macosx/extras/intel/Hardware_Accelerated_Execution_Manager 資料夾裡面有一個 HAXM installation執行檔，可以重新安裝 HAXM(Intel Hardware Accelerated Execution Manager)，增加記憶體用量:

$ ./HAXM\ installation -m <最大記憶體使用量>

例如，我想同時間開啟 Nexus 5X，跟 Nexus 5P。這兩支各別都是 1.5 GB的記憶體使用量，所以需要把 HAX 增加到 3072MB:

$ ./HAXM\ installation -m 3072

安裝完成之後就可以同時開兩個 Android emulator 了:

不廢話 App 成長指南 筆記

2015 December 02 Wed

成長的秘密

讓少數的使用者熱愛你的產品，而不是擁有一堆對這個產品漠不關心的使用者

It’s better to make something a small number of people love than something a large number of people don’t care about.” -Paul Buchheit

在擴展產品之前，你必須專注在user engagment，讓這個 App 會吸引使用者的注意。

成長指標

首先要找到一個適合的 App 的成長指標，可透過下列的兩個問題來尋找:

  1. 那一個指標可以證明這個 App 的確有解決使用者的問題？
  2. 這個指標的發生的頻率多久才是對使用者有意義的？

例如: 遊戲(天) < 天氣(天) < 手電筒(月) < 旅行(月)

你就不應該期待一個平常的使用者會每天都開手電筒的 App.

持續改善

當找到使用者參與指標(User engagement metric)的之後， 就可以用這些資料來改善 App。一般來說可以從 Google Analytics 和 Mixpanel 開始。當產品做了一些修正的時侯，持續關注使用者參與指標，確保 App 是往正確的道路上

如果想更深入了解，可參考:AdMob No-Nonsense Guide to Growing Your Mobile App

Postgresql 常用的指令

2015 December 02 Wed

最近一年比較常使用 postgresql 資料庫系統，這篇把一些常用的指令整理一下:

安裝 postgresql server

In Ubuntu:

$ sudo apt-get update
$ sudo apt-get install postgresql postgresql-contrib

In OSX，使用 homebrew: 

$ brew upgrade postgresql

建立 DB

$ initdb ~/pgdata

啟動 postgresql server

$ pg_ctl -D ~/pgdata start

連線到指定的 DB

$ psql -h localhost -p 5432 -d docker -U docker --password

備份資料庫

把 database 匯出成一個 sql 文字檔案

$ pg_dump -U {user-name} {source_db} -f {dumpfilename.sql} -h {host} -p {port}

匯入資料庫

從 sql 文字檔案匯入到 database

$ psql -U {user-name} -d {desintation_db} -f {dumpfilename.sql}

刪掉資料庫

$ dropdb {database_name}

日本達摩翁的故鄉 - 群馬縣高崎市

2015 November 19 Thu

群馬縣高崎市

高崎是是群馬縣西南方的一個人口近40萬的城市，以日本達摩翁聞名。

高崎 JR 車站、商店隨處可見各式各樣的達摩翁擺設。

從東京搭乘新幹線到高崎車程約一個小時。我們是從東京出發，搭乘北陸新幹線的淺間（Asama) 611號列車。

淺間號列車是以聳立在群馬縣和長野縣間的淺間山為名:

高崎市離輕井澤新幹線車程只有15分鐘，許多遊玩輕井澤的旅客也會選擇住在住宿費用比較便宜的高崎市。

免費市區單車

在高崎市的行程原本是打算用公車+步行來完成的，但在路上意外看到有免費的市區單車，那就想說不如就改成單車之旅吧。

租借方式很簡單，就像台灣大賣場的推車一樣，塞入100元硬幣，就可以騎走了，對於觀光客而言可說非常的方便。

目前在市區共有15個租借點:

租借時間只有從 AM9:00 到 PM10:00，而在租借時間之外，腳踏車會被鎖上鐵鍊的。

達摩的故鄉

高崎開往長野原草津口的路上，我們搭了草津3號，在車上買了全國知名的日本鐵道便當: 達摩茶飯便當

來源

回台灣之後，這個達摩就成我的零錢存錢筒，是一個相當實用的記念品。

在高崎市，我們就騎著單車，往達摩翁工廠大門屋方向慢慢騎去

大門屋

達摩點睛的說明 達摩翁可幫助你完成願望，當你許願的時侯，先點上左眼。待願望完成之時，就再點上右眼，並把達摩翁帶回達磨寺焚化供奉。

當然，我們也不忘帶了幾尊達摩翁回家

高崎可可大飯店

這次在高崎市住的是高崎可可大飯店(Hotel Coco Grand Takasaki)，雙人房一晚約14000日幣。在 Trip Adavisor 有極高的評價。下次會想再來

餐點資訊:

  1. 早餐 Buffet: 1200 日幣
  2. 午餐套餐: 1800 ~ 2000 日幣

使用 Bower 來管理 web 函式庫套件

2015 November 08 Sun

Bower 是 frontend 常用來管理 package 的套件。比如說要使用 jquery，就可以透過 bower，來安裝。

安裝

$ npm install -g bower

註: 如果權限不足的話，記得加上 sudo

初始化

$ bower init

bower 是透過 bower.json 來管理 dependecy，所以一開始要先透過這個指令來新增 bower.json，過程會問一些問題，可以按 enter 直接用預設的即可。

搜尋，以 jQuery 為例

$ bower search jquery

輸出: 

Search results:

    jQuery https://github.com/jquery/jquery.git
    jquery https://github.com/jquery/jquery-dist.git
    jquery.x https://github.com/jljLabs/jquery.x.git

列出可以使用的 repository

安裝，以 jQuery 為例

$ bower install jquery

安裝完之後，目錄會出現 bower_components 來存放 jquery 的檔案:

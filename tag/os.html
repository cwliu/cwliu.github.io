Install Juniper on Ubuntu 14.04

2014 June 20 Fri

On Ubuntu 14.04, install Juniper VPN

$ update-alternatives --display java

Requirement

64 bit Mozilla Firefox browser is installed

First, install the 64bit jre/jdk and icedtea

$ sudo apt-get install openjdk-7-jre icedtea-7-plugin

Second, install the 32bit jre

$ sudo apt-get install openjdk-7-jre:i386

link update-alternatives to /usr/sbin/

juniper use it in that folder. 

$ sudo ln -s /usr/bin/update-alternatives /usr/sbin/

Install TeamView 9 in Ubuntu

2014 January 01 Wed

Install TeamView Ubuntu 13.10 64-bit

$ cd ~/Downloads/ && wget http://download.teamviewer.com/download/version_9x/teamviewer_linux.deb
$ sudo apt-get install gdebi
$ sudo gdebi ~/Downloads/teamviewer_linux.deb

讓 TeamView 不要偷偷在背景執行

sudo teamviewer --daemon disable

Windows 7 安裝 Virtual Smart Card Reader in Workstation 8.0

2012 August 21 Tue

VMware Workstation 8.0 有支援使用 Smart Card Reader的功能，我的 Guest 是 Windows 7 Pro x86，裡面的Virtual Smart Card Reader 就怎麼樣就是裝不起來，顯示驅動程式安裝不成功。 Google 了一下，找到了解法，關鍵字就是 554522.cab 這個 Driver。

解法︰

  1. 下載 Cab 檔︰ Link
  2. 解開裡面的 usbccid.* 的三個檔案
  3. 去 Device Manage，找到那個有驚嘆號的 Smart Card Reader
  4. 更新 Driver，手動選擇 Device Type，然後選 Smart Card Driver

接下來一直 Next , Next .. 就可以安裝完成了。

NAMP 是一套網路掃描的工具

Nmap

$ nmap ip

$ nmap [ip1 ip2]

$ namp 192.168.10.1/24

隨機掃描目標(慎用)

$ nmap -iR 3

Ping

$ nmap 172.16.21.134 172.16.21.135 -sP

TCP SYN Ping

當系統把 ICMP PING 關掉的時間可以改試 TCP SYN PING。 

$ nmap -PS135 172.16.21.131

UDP Ping

# nmap -PU 172.16.21.131

偵測作業系統

# mmap -O 172.16.21.134
